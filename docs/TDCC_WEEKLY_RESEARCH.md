# 官方 TDCC 集保股權分散每週研究試驗

## 來源
TDCC 官方集保戶股權分散表： https://opendata.tdcc.com.tw/getOD.ashx?id=1-5 。由集保結算所依每週最後一個營業日的集保帳載持股統計，**不是當天逐筆成交數據，也不能把同一週數字填滿每天**。官方說明：https://www.tdcc.com.tw/portal/zh/smWeb/qryStock ，政府標準：https://schema.gov.tw/lists/75 。

## 第一步
週六台灣時間10:30以 GitHub Actions「Official TDCC Weekly Research Pilot」自動取得最新快照（首次合併時亦跑一次）；驗證CSV編碼、資料日期、證券代號、分級1–17、持有人數、股數、集保持股比例。持股分級16是差異調整，不應直接算為某種大戶族群；17為合計。

儲存到獨立 data/tdcc_weekly_research/YYYY-MM-DD.json.gz，只保留官方現存公司母檔內，且全部17級完整、總股數守恆的公司。資料日期不得在未來，也不能超過14日未更新。至少有1000間公司通過檢查，否則拒絕本次回補；若同日期已存在卻與現有檔案不同，停止覆寫並待稽核。

### 不可誤解的比例
資料會保存第15級股數及占集保股數比例，但它**不是所有大戶集中度定義，更不能直接假設等於1,000張以上持股比例**。須核對 TDCC 每一持股級距與分母定義，未來需要不同級距之加總、週別相對應的發布時點和歷史可得性驗證，才可進入籌碼因子。

所有研究結果固定不發布Top 10、不模擬任何買進、不產生Telegram推薦，也不修改原本22檔風險提醒。股價除權息未還原、歷史公司母體、融資／借券、點時點財報和稅費滑價回測尚未完成。

## 異常股數處理
2026-11-14 首次真實TDCC官方資料抓取遭拒（tdcc_holding_total_mismatch）：不是缺Token，而是部分股票的1–16級股數加總與17級合計不相符。公開網站的說明亦提及差異數調整與特殊帳戶情形，不能任意把差額改為零。

目前採保守隔離策略：逐公司檢查，不符者完全排除於可用研究公司清單之外，留下隔離數量和至多12個代號供後續人工追溯；若不一致公司超過25檔或當期公司母體的5%（取較高門檻），整週仍拒絕入庫，並保留原始驗證失敗訊息。至少1,000間完全驗證公司才允許檔案入庫，未經驗證的個股不會被算入任何大戶比例。

**這不是自動修正集保差異數，也不能藉此宣稱歷史股權分散資料的所有公司都完整**。未來尚需核對每家公司全17級、級距事件、減資、週資料發布時間及歷史公司母體，才可進一步建構可信的週因子。
