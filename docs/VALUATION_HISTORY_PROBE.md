# 官方歷史估值資料來源探測（P/E、P/B、現金殖利率）

## 為什麼先探測，而不是直接產生排名
官方上市櫃資料有「日本益比、殖利率、股價淨值比」頁面，但歷史日期能否真正查到不同結果、官方欄位是否穩定、是否包含當時已公布的財報年度／季別，需要先驗證；不能把今天才知道的財報數字倒填到過去交易日。

## 官方資料來源
- 上市：臺灣證券交易所 BWIBBU_d，依日期查詢。https://www.twse.com.tw/rwd/zh/afterTrading/BWIBBU_d
- 上櫃：櫃買中心「上櫃個股本益比、殖利率、股價淨值比」（歷史查詢）https://www.tpex.org.tw/web/stock/aftertrading/peratio_analysis/pera_result.php
- 依2026-11-12與2026-11-13兩個正式交易日查詢，至少需達規定公司筆數、來源表格結構合格且跨日内容雜湊不同；不接受「網址改了日期但回傳一樣」的偽歷史資料。
- 目前對來源資料的檢查僅限「兩日期內容不同」，不是回應明示對應日期，也不是財報發布時點的完整驗證。網路錯誤、表格結構差異、來源無資料會中止。

## 執行方式
- GitHub Actions → Official Dated Valuation Historical Source Probe → Run workflow。
- 本 PR 合併 main 時會自動執行一次，並留下名為 official-valuation-history-probe 的30日診斷。
- 此版本**只探測，不將數據併入量化分數**；尚未採集五年EPS、ROE、實際公告日。
- 來源URL、歷史數據、欄位和發布時點不完整前，Top10與Telegram選股通知繼續關閉。

## 後續研發
要使財報因子可回測，必須核對公司財報實際公布日期、現金股利與股本變動、當時上市櫃母體、缺值、次一交易日可得性，以及包含手續費、證交稅與滑價的樣本外績效。上述品質關卡完成前不提供正式買賣勝率。
