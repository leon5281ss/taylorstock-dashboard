# 上市櫃全市場量化選股（資料完整性優先）

## 目標與目前邊界

本次 PR 建立 **全上市櫃普通公司股票** 母檔抓取、固定多因子模型、資料完整性閘門、每天 21:55（GitHub schedule 非精準）的 readiness artifact。**目前尚未接入全市場歷史價量、法人／融資、借券、TDCC 大戶、五年財報及即時估值的資料儲存庫，因此不發布 Top 10，也不聲稱已完成每日全市場自動選股。**

獨立工作流程「Full Market Quant Readiness」，與22檔監控不互相干擾。目標是先能每天核對上市／上櫃官方股票母檔與缺資料程度。

## 官方母檔來源

- 上市公司基本資料：https://openapi.twse.com.tw/v1/opendata/t187ap03_L
- 上櫃公司基本資料：https://www.tpex.org.tw/openapi/v1/mopsfin_t187ap03_O
- 上櫃官方 CSV 備援：https://mopsfin.twse.com.tw/opendata/t187ap03_O.csv

逐市場標示來源；無法取得或資料筆數異常時拒絕宣稱完整。只包含四位數非0開頭普通公司代號，排除 ETF、ETN、權證；檔案不推測已下市公司。母檔是**目前可取得的公司名單**，不能拿來回測歷史存活偏誤。

## 權重與計算

| 因子 | 權重 | 必備欄位 |
|---|---:|---|
| 技術動能 | 35% | 至少121筆除權息檢查過的日線、MA5/20/60/120、RSI14、MACD、5/20日動能 |
| 籌碼 | 25% | 近5日外資／投信、融資、借券餘額、TDCC大戶比例 |
| 基本面 | 25% | 5年EPS、EPS TTM、營收年增率、ROE、營業利益率，及財報發布日 |
| 估值風險 | 15% | 當日PE、PB、現金殖利率、20日歷史波動度、成交金額流動性 |

本模組先產生因子特徵；完整上市櫃資料到齊後，才以所有股票的相對百分位數給分，並依 35／25／25／15 加權。缺資料為 **null／不可評分**，不以50分填補、不降權重或虛構勝率。正式 Top10 僅在兩市場官方母檔與每一檔的全部必要因子都完整、日期一致、發布日不穿越時提供；資料不足時 top10 = null。

輸入補齊為私人驗證資料 JSON（asOf + stocks 對照代號），此 PR 不含自動取得大戶、五年歷史、全市場批次資料的授權／儲存服務。需另做資料管線與歷史除權息、下市樣本、回測費稅及滑價，才能將分數用於實際選股。
