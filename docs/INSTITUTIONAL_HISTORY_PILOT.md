# 官方逐日三大法人歷史淨買賣研究試驗

## 來源與口徑
上市使用臺灣證交所 rwd/zh/fund/T86 帶日期端點，上櫃使用櫃買中心 www/zh-tw/insti/dailyTrade 帶日期端點。前一階段 PR #19 已對 2026-11-12、13 做真實官方驗證，兩日期均明示且不同，上市分別1347、1349列，上櫃898、896列；不同來源原始列數不是公司股票數。

本階段只做2026-11-13的一天研究試驗，依現行官方公司名單篩選四碼上市櫃普通股票。單位統一為股，三大法人數據分別為外資及陸資（**不含外資自營商**）淨買賣、投信淨買賣、自營商自行買賣加避險後的淨買賣。**不將「外資買進總量」誤當成外資買賣超，也不將「外資自營商」另外加入外資淨額造成重複。**

## 資料驗證
- 上市依官方19欄確定的欄名與位置，不以模糊關鍵詞比對。
- 上櫃資料24欄中有七組同名的買進、賣出、買賣超，強制位置一致。每組都以買進減賣出驗證淨額；再核對外資合計、自營自行買賣加避險、三大法人合計三種守恆式。
- 每市場僅採與現行公司母檔匹配的標的；同市場重複代號、來源日不符、來源表結構變更、會計守恆式矛盾直接拒絕。
- 必須至少有65%的現存公司有合格淨額資料；缺值不能擅自補零，否則會誤判法人進出。
- 資料存於 data/institutional_research/YYYY-MM-DD.json.gz，與公開當日行情、未調整研究價量、除權息事件分開，並利用安全提交程序避免主分支推送競爭。
- Actions／行動 → Official Institutional History Pilot；合併時自動試驗 2026-11-13，亦可手動選日期，但每次只核對一天。

## 安全邊界
這些是研究用途，使用「目前」上市／上櫃名單，尚未還原當時上市櫃公司成分，未建立完整歷史可交易股票母體。此資料不能直接與尚未統一量口徑的成交量計算籌碼比率，也不包含TDCC、借券、融資、公司財報及除權息後真實股價。資料標記 institutional_history_research_only、top10=null、publishable=false，不會發布買賣建議或 Telegram 量化排名。

本模組實際成功抓到並通過官方端點之後，下一階段才適合按研究行情歸檔日期逐批回補法人歷史，並處理前述品質問題。
