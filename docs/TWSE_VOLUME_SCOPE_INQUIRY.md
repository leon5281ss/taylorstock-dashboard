## 官方回覆證據登錄格式

每次回覆獨立登錄。原始電郵及附件留存於受控證據目錄，公開研究只引用可公開的官方文件。

| 欄位 | 登錄方式 |
| --- | --- |
| receivedAt、caseId | 含時區的 ISO 8601 回覆時間，以及官方案件或函文編號。未提供時填 null。 |
| issuer、channel | 官方機關及回覆管道。核對寄件網域、案件入口或正式函文。 |
| documents | 每份文件的標題、原始網址或文件識別碼、版本、生效日及原始檔 SHA-256。 |
| mappings | 每個端點、欄位、商品版本及單位獨立一筆，填寫 applicableFrom、applicableThrough，以及逐項交易類別的 included、excluded 或 unknown。 |
| evidenceLocator | 每項映射引用的文件識別碼及頁碼、表格或段落。 |
| revisions | 修訂版本、生效日、變動欄位、是否追溯，以及取代的證據識別碼。 |
| reviewStatus | pending、verified 或 conflicting。缺少可追溯的官方明文、適用日或版本時維持 pending。 |

交易類別固定分列一般交易、盤中零股、盤後零股、盤後定價、單一證券鉅額、組合鉅額。BFT41U 的單位與 BFIAUU 的去重及重疊定義各自登錄。加入正式口徑證據前，確認資料覆蓋完整 60 個交易日；股數相符及欄位一致只保留為研究觀測。
